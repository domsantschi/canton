CANTON · LOCAL DEMO ONLY

Private auction

Explore party-filtered contracts on your local Canton participant.

Not authentication. Anyone using this local demo can switch identities. It signs unsafe LocalNet JWTs on the server and controls all five parties. Never expose this app or use it for production.

1. Connect to LocalNet

Uses only localhost:3975. Build the model first with dpm build (SDK 3.4.11). Setup requires and uploads the DAR, then provisions five party users.

Not connected.

2. Switch perspective

Each view is queried with its own user and one party filter. Outsider should see no auction contracts.

Active contracts

Connect to view contracts.

3. Act as the selected party

Open as auctioneer and choose Alice, Bob and Carol in invitation order; that order breaks ties. Submit one bid per bidder, then close as auctioneer with bids ordered by invitation. Issue credit to the winner as auctioneer, then pay as winner. Credit is issuer-backed ledger credit, not cash.

To test bid tampering, paste a saved Bid ID while viewing as one party. Bid Archive requires both signatories; another bidder's bid may also be invisible. Rejection is expected, not guaranteed by this interface. Errors are returned by the ledger; successful actions refresh this view.

Action / error log

Ledger rejections appear here. Log entries can reveal private information; clear them before switching perspectives.
